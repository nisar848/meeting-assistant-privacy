# Meeting Assistant Privacy Policy

This repository contains the privacy policy for the **Meeting Assistant GPT**.

Meeting Assistant GPT helps users process meeting transcripts, generate meeting minutes, identify action items, and manage tasks. It may also connect to supported third-party services such as Trello when authorized by the user.

## Privacy Policy

The full privacy policy is available here:

https://nisar848.github.io/meeting-assistant-privacy/

## Connected Services

Meeting Assistant GPT may support integrations with services such as:

- OpenAI / ChatGPT
- Atlassian / Trello
- GitHub Pages

Users must authorize access before the GPT can interact with connected third-party accounts.

## Security

Do not submit passwords, API keys, access tokens, client secrets, or other sensitive credentials through this repository or through a ChatGPT conversation.

## Contact

For privacy-related questions or concerns, open an issue in this repository:
